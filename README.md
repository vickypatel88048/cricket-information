# AutoExam 🚀

AI-powered exam automation SaaS for coaching institutes and teachers.

## Current MVP
- Teacher dashboard
- AI question generator demo
- Question bank
- Test management
- Student management
- Analytics dashboard
- Student quiz preview
- Automatic score calculation
- Responsive UI

## Run locally
```bash
npm install
npm run dev
```
